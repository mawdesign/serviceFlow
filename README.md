**A lightweight, blazing-fast, cross-platform media & worship presentation engine. Built in Rust.**

`serviceFlow` is the desktop and web-assembly client for the **Lyric Sanctuary** suite, designed to manage and run entire services from start to finish. Originally inspired by OpenSong, `serviceFlow` reimagines live presentation from the ground up—moving beyond just songs to orchestrate your entire "run of show" including sermon slides, video playback, notices, and chord sheets.

Built natively in pure Rust, it delivers ultra-low latency, robust multi-screen projection, and instant web access without the bloated footprint of legacy systems.

### ✨ Key Features

*   **🎬 Beyond Songs:** Manage your entire service timeline—seamlessly transition from notices and video roll-outs to sermon slides and responsive chord charts.
*   **🦀 Powered by Rust:** Insanely fast, crash-resistant, and memory-efficient. Start-up is instant, even on older church laptops.
*   **💻 Cross-Platform & WASM:** Fully native desktop apps (macOS, Windows, Linux) and a rich WebAssembly client. View on stage tablets, run from any browser, or cast anywhere.
*   **🎶 Built-in Transposition & Chords:** Display chords above lyrics with instant, on-the-fly key transposition, integrating directly with the Lyric Sanctuary online ecosystem.
*   **🖼️ Dual-Screen & Output Orchestration:** Advanced, dual-screen output management with support for overlays, lower-thirds, and stage displays.
*   **📂 OpenSong & XML Compatibility:** Full legacy support to easily import your existing OpenSong databases, with an updated, modern presentation flow.
